# Source register — verified 2026-09-06

This register distinguishes **existing parsed data**, **newly obtained original responses**, and **publisher documentation**. A reachable homepage alone is not a verified dataset. The current analysis window remains 2015–2023; broader source histories listed here do not authorize expansion. Original download dates/versions of the pre-existing CSVs are unknown. Today's verification dates must not be substituted for those original dates.

New public downloads are content-hashed under `output/source_verification/`; HTTP outcomes, timestamps, URLs and SHA-256 hashes are in `evidence/download_attempts_*.csv`. API probes retain response data and metadata without request credentials. `evidence/source_snapshot_manifest.csv` hashes the entire current cache, including API responses. `evidence/source_comparison.csv` reports numeric reconciliation of selected measures, using tolerance `1e-7 * max(1, abs(old))`. Equality of selected values does not establish that all source metadata or all unused columns were validated. No existing raw files were overwritten.

## USGS — required outcome

- Publisher: U.S. Geological Survey, National Minerals Information Center. [Dataset landing page](https://www.usgs.gov/media/files/usgs-aggregates-time-series-data-state-type-and-end-use), dated April 3, 2025; [original workbook](https://d9-wret.s3.us-west-2.amazonaws.com/assets/palladium/production/s3fs-public/media/files/USGS_Aggregates_Data-1971-2023.xlsx).
- Identifier: `USGS_Aggregates_Data-1971-2023.xlsx`, sheet `Data_1971_2023`, Table 2 / `Data Description = State totals`, `Commodity = Stone, crushed`, `Quantity`. Companion `Total Value` and `Unit Value` are descriptive only.
- Frequency/geography/availability: annual; 50 named states, 1971–2023 in the state table; all nine requested years verified. National table is separately available for 2000–2023.
- Units/meaning: metric tons sold or used; total value in dollars; unit value dollars per metric ton. Embedded workbook instructions specify that stockpiles are excluded and imported/interstate material is attributed to first sale/use. Thus state totals do not necessarily describe extraction inside state borders.
- Data process: producer survey plus USGS estimation for nonrespondents using MSHA hours; state-total rows do not separate observed and estimated contributions. Values are rounded, generally to three significant digits. Revisions and rounding can prevent table totals from adding exactly.
- Suppression: all 23 missing target entries are `W` in the downloaded workbook. Preserve that flag, do not impute zero. Delaware/Louisiana 2015–2023 and Nebraska 2019–2023 are withheld. `evidence/usgs_target_tokens.csv` retains all 450 source quantity tokens. Exact numeric target values match the saved CSV.
- Decision: retain; clarify target name and geography. Source-construction dependence makes MSHA hours a restricted secondary feature. Preserve `evidence/usgs_workbook_instructions.txt`, extracted completely from the embedded DOCX.

## Census — Building Permits Survey (BPS)

- Publisher: U.S. Census Bureau. [BPS](https://www.census.gov/construction/bps/index.html); annual state files follow `https://www2.census.gov/econ/bps/State/stYYYYa.txt` ([2015](https://www2.census.gov/econ/bps/State/st2015a.txt), [2023](https://www2.census.gov/econ/bps/State/st2023a.txt)); exact nine URLs are in `evidence/source_urls.csv`.
- Frequency/geography/availability: annual state files, all 2015–2023 downloaded and parsed; 50-state restriction yields 450 rows. BPS also provides monthly estimates; this project uses annual data.
- Identifiers/units: `units_1unit`, `units_2unit`, `units_34unit`, `units_5punit` are counts of authorized housing units; `bldgs_*` counts buildings; `value_*` are thousands of dollars of permit valuation, confirmed in [state ASCII documentation](https://www.census.gov/construction/bps/sample/stateasc.pdf). `time` annual codes end in `99`. `_rep` columns are reported-only counterparts, not additional activity.
- Data process: published estimates include Census imputation for nonreporting jurisdictions; treat them as survey estimates, not a census of verified completions. [Census methodology](https://www.census.gov/construction/bps/methodology.html) documents reporting, annual totals and imputation. Summing the four unit categories is a project aggregation, not project imputation. Permits indicate authorizations, not starts or completions.
- Breaks/revisions: [2023 methodology notice](https://www.census.gov/construction/pdf/bps_2023_faqs.pdf) documents the switch from a fixed universe to annual updating. Record 2023 as a comparability consideration, not an automatic exclusion. Current metadata may describe later imputation changes that must not be backdated to 2015–2023 without evidence.
- Verification: no missing numeric permit fields in saved files; all four primary unit-count components match fresh downloads for all 450 rows. Keep `_rep` for quality sensitivity; exclude it from the primary sum. Retain as primary.

## FHWA — highway capital outlays

- Publisher: Federal Highway Administration. Highway Statistics **SF-4C**, Disbursements for State-Administered Highways, classified by function. [2015 table](https://www.fhwa.dot.gov/policyinformation/statistics/2015/sf4c.cfm), [2023 table](https://www.fhwa.dot.gov/policyinformation/statistics/2023/sf4c.cfm). Each year's authoritative HTML and workbook use `/policyinformation/statistics/YYYY/sf4c.cfm` and `/policyinformation/statistics/YYYY/xls/sf4c.xlsx` respectively. All nine HTML tables were inspected.
- Frequency/geography/availability: annual reporting-year tables; 50 states after filtering. Existing files contain 450 rows for 2015–2023. These are state-administered highway expenditures, not all federal/state/local spending or a future appropriations series. Debt service is excluded. Year labels alone do not establish the underlying expenditure year.
- Units/identifiers: thousands of nominal dollars; `capital_outlay_total` comprises right-of-way acquisition, engineering, construction/system preservation. Use either total or construction/preservation component in a sensitivity analysis, not all components and their total together.
- Footnotes: eight source rows explicitly reuse older years; [ledger](evidence/fhwa_reporting_year_flags.csv) maps table year, state and reported year with supporting URLs. Massachusetts 2015/2016 uses 2011 data; Rhode Island 2015 uses 2013; Alaska 2017 uses 2016; Massachusetts and Oregon 2018 use 2017; Oregon 2019 uses 2017; Massachusetts 2020 uses 2019. Exclude these values from strict same-/prior-year tests; do not relabel/reinsert them into earlier years and create duplicates. The eight raw missing FIPS are a second, separate issue.
- Missingness: HTML dashes/blank categories and numeric workbook zeros require format-aware handling. The publisher notes incomplete classification where entries do not appear; do not globally interpret every blank as zero. All existing primary capital totals are numeric. Inspect carried-forward values as source reporting limitations, not project imputation.
- Verification limitation: one 2023 original workbook downloaded successfully and all 50 capital totals match. Repeated binary requests subsequently failed certificate-chain validation, including 2015–2022. No TLS verification was disabled. The successful command was `curl --fail --location --silent --show-error --connect-timeout 10 --max-time 30 'https://www.fhwa.dot.gov/policyinformation/statistics/2023/xls/sf4c.xlsx' --output /private/tmp/mdata-sf4c-2023.xlsx`; the resulting bytes were copied unchanged to the content-hash cache and indexed in `evidence/fhwa_2023_success.csv`. Source release labels/footnotes take precedence over stale HTML page titles or modification dates (the 2021 page title, for example, says 2020).
- Decision: primary subject to explicit timing masks and Phase 2 source reconciliation. Strong alternative: secondary-only if binary access/reconciliation remains unresolved. Specific construction-cost deflation is not currently available in this source inventory.

## BEA — construction GDP, total GDP and income

- Publisher: Bureau of Economic Analysis. [Regional API guide](https://apps.bea.gov/api/_pdf/bea_web_service_api_user_guide.pdf); endpoint `https://apps.bea.gov/api/data/`.
- Request identifiers: `method=GetData`, `DataSetName=Regional`, `GeoFips=STATE`, `Year=2015,...,2023`. `SAGDP9 / LineCode 11` = construction (NAICS 23); `SAGDP9 / LineCode 1` = total real GDP; `SAINC1 / LineCode 1` = personal income. Construction LineCode 11 was verified from `GetParameterValuesFiltered`, not assumed. Metadata description is prefixed (`[SAGDP9] Real GDP by state: Construction (23)`), so a strict equal-to-Construction match alone fails; the existing import's fallback resolves it.
- Frequency/geography/history: annual; state tables also return national/regional/DC entries, which must be removed using an exact state mapping. SAGDP9 history begins in 1997; SAINC1 in 1929 with historical Alaska/Hawaii limitations. All 50 states and 2015–2023 verified here. State names can carry `*` footnotes; stripping these for matching must not discard notes.
- Units: both GDP variables are **millions of chained 2017 dollars**, `UNIT_MULT=6`; income is **millions of current dollars**. Unit multiplier alone does not identify the real-dollar base year. Read `CL_UNIT`; do not hard-code a future base year silently. Sector GDP measures value added, not total construction spending.
- Version: saved fresh API notes identify an April 9, 2026 update; income notes explicitly mention revised 2020–2024 statistics. Contemporary revisions prevent claims of historical real-time information availability. Details in `evidence/bea_*_metadata.txt` and cached JSON.
- Verification: authenticated data responses for all three measures and metadata; compared state-year values match existing inputs. Generic numeric parsing must explicitly handle BEA annotations such as `(D)`, `(L)`, `(NA)` if encountered; none appear in the selected numeric state-year measures inspected here. Retain construction as primary; GDP/income only as alternative controls to avoid redundant state-size measures.

## BLS — state heavy/civil employment

- Publisher: Bureau of Labor Statistics, CES State and Area program. [Program questions and series availability](https://www.bls.gov/sae/questions-and-answers.htm); endpoint `https://api.bls.gov/publicAPI/v2/timeseries/data/`.
- Series pattern: `SMU{two-digit-state-FIPS}000002023700001`, e.g. `SMU01000002023700001` for Alabama. NAICS 237, all employees in thousands, not seasonally adjusted. The raw field `construction_employment_thousands` is more specific than its name suggests.
- Frequency/history: monthly source; project arithmetic mean of M01–M12, excluding M13 annual-average rows. Selected series verified across 2015–2023 for 36 states, 324 state-years with exactly 12 monthly observations each. Program-wide history does not establish availability of a particular detailed state industry.
- Availability: fresh API reports no series for Alaska, Arkansas, Connecticut, Delaware, Hawaii, Iowa, Mississippi, Missouri, Nevada, New Hampshire, New Mexico, Rhode Island, Vermont and West Virginia. Preserve missingness. The intersection with observed targets is 310 rows. Counts are estimates subject to CES revisions/benchmarking; monthly observations and footnotes were not retained in existing annual CSVs but are available in the new response cache.
- Decision: secondary subset comparison with its own baseline on identical observations. Broader total construction is an unverified alternative feature, not an interchangeable fill for missing heavy/civil employment.

## FRED — national mortgage and CPI context

- Distributor: Federal Reserve Bank of St. Louis. Original publishers: Freddie Mac for [MORTGAGE30US](https://fred.stlouisfed.org/series/MORTGAGE30US), BLS for [CPIAUCSL](https://fred.stlouisfed.org/series/CPIAUCSL). Endpoint `https://api.stlouisfed.org/fred/series/observations`; authenticated queries use series ID, observation dates and JSON format.
- Units/frequency/geography: mortgage is percent, weekly ending Thursday, not seasonally adjusted; CPI is monthly, seasonally adjusted, 1982–84=100. Both national only. Project annual arithmetic means are calculated from weekly/monthly observations; annual inflation is percent change of annual-mean CPI, not December-over-December inflation.
- Access/years: authenticated observations downloaded for 2014–2023, including 12 CPI values for 2014. Existing source/clean data only cover 2015–2023; saved raw inflation exists but its required 2014 source input does not. Fresh annual means match saved 2015–2023 means. `evidence/verified_cpi_annual.csv` documents the support-year recovery without modifying raw data.
- Footnotes: mortgage survey methodology changed November 17, 2022; CPI seasonally adjusted history can be revised. `.` indicates missing FRED values; enforce observation counts before averaging. Never treat copied national values as state variation. Year fixed effects absorb both series completely.
- Decision: CPI is a possible transparent monetary normalization input; mortgage/inflation are context or limited predictive alternatives. A consumer price index does not specifically measure quarry/highway input costs.

## Census — value of construction put in place

- Publisher: U.S. Census Bureau. [Historical construction spending](https://www.census.gov/construction/c30/historical_data.html). Four verified originals: [private nonresidential history](https://www.census.gov/construction/c30/xlsx/nrstatehs1.xlsx), [private current](https://www.census.gov/construction/c30/xlsx/nrstate.xlsx), [state/local history](https://www.census.gov/construction/c30/xlsx/slstatehs.xlsx), [state/local current](https://www.census.gov/construction/c30/xlsx/slstate.xlsx).
- Frequency/geography/history: annual state estimates. Downloaded private history 2008–2021, state/local history 2006–2021; current workbooks both 2022–2025. Their requested 2015–2023 portions each yield 450 state-years. Newer years are not added to the analytical window.
- Units/definitions: millions of nominal dollars; private nonresidential geography tables exclude **power, communication and railroad**. State/local ownership is distinct from private ownership and overlaps conceptually with highway outlays. Counts/values are Census estimates, not purely observed transactions; current files include RSE columns, which existing imports discard.
- Revisions/selection: use current over history for overlapping years, preserve selected filename/year provenance; the present snapshots do not overlap over 2015–2023. Do not treat RSE as an additional year. Footnotes warn about rounding/nonadditivity. Inspect suppression/non-numeric tokens before parsing; selected state-year totals are numeric and match saved values.
- Decision: secondary substitutions with deflation/overlap caveats, not automatic additional predictors.

## EIA — State Energy Data System prices

- Publisher: Energy Information Administration, SEDS. [Bulk price CSV](https://www.eia.gov/state/seds/sep_prices/total/csv/pr_all.csv), [codebook](https://www.eia.gov/state/seds/CDF/Codes_and_Descriptions.xlsx). Both downloaded and inspected.
- Identifiers/units: `DFICD` industrial distillate, `ESICD` industrial electricity, `NGICD` industrial natural gas (including supplemental gaseous fuels), `TEICD` total industrial energy average price; all **dollars per million Btu**, not electricity cents/kWh or fuel dollars/gallon. Codebook sheet `MSN descriptions` confirms these definitions.
- Frequency/geography/availability: annual state estimates; bulk table has historical year columns, with all requested 2015–2023 years verified for all 50 states (450 rows for each selected price). Exact full-file year bounds are recorded in `evidence/source_available_years.csv`; broad availability does not authorize expanded modeling.
- Limitations: modeled/aggregated sector prices, not observed quarry-specific costs; total and component prices overlap. Current downloads may revise prior years. No missing selected prices were found; preserve any future source not-available tokens as missing, not zero. All four measures match saved values.
- Decision: one cost feature at a time in secondary sensitivity analysis, with explicit nominal/constant-price treatment.

## MSHA — activity proxies, not measured stone output

**Phase 2 correction:** the Gate 1 comparison reused a quote parser that merged records. The approved pipeline reads all 92,000 mine-master rows with zero parsing problems and strips only field-enclosing quotes from analytical columns. Corrected counts/hours differ from the legacy file in 256 state-years. See `evidence/phase2_parser_correction.md` and `../output/tables/msha_parser_correction.csv`; the legacy-match statement below describes only the earlier audit, not the corrected data.

- Publisher: Mine Safety and Health Administration. [Open-data portal](https://arlweb.msha.gov/OpenGovernmentData/OGIMSHA.asp); [annual employment archive](https://arlweb.msha.gov/OpenGovernmentData/DataSets/MinesProdYearly.zip), [mine archive](https://arlweb.msha.gov/OpenGovernmentData/DataSets/Mines.zip), [mine dictionary](https://arlweb.msha.gov/OpenGovernmentData/DataSets/Mines_Definition_File.txt), [annual dictionary](https://arlweb.msha.gov/OpenGovernmentData/DataSets/MinesProdYearly_Definition_File.txt). All obtained. Archives contain expected text members and schemas.
- Frequency/geography/history: mine/subunit/year, aggregated by state. Annual employment records start in 2000 per publisher; mine master includes historical mines and current descriptors. All 2015–2023 state-year aggregates recomputed from cached originals; selected counts/hours match saved data. The source is updated frequently, not a fixed historical classification archive.
- Filters/units: primary canvass `6` = stone, subunit `03` = strip/quarry/open pit, metal/nonmetal indicator `M`; retain positive annual hours or average annual employment. Units: mine counts, annual hours, and average employees. These exclude other subunits and contractor activity. Nonmetal operators need not report production; coal tonnage is not a crushed-stone outcome.
- Limitations: current primary commodity used for historical classification; portables, coverage and zero-fill assumptions need visibility. `stone_mine_operations` duplicates active-mine counts after mine/state/year aggregation. Dictionary legacy names differ from archive headers (e.g. `CAL_YR` vs `CALENDAR_YR`); validate actual headers explicitly. Current counts cannot establish installed physical capacity.
- Decision: restrict to secondary sensitivity. USGS estimation already uses worker hours, creating measurement dependence; lagging reduces simultaneity but does not prove independence or causation. No contemporaneous hours in the primary design.
